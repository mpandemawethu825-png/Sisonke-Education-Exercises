Series and Sequences • Full Playlist + Detailed Solutions

In earlier grades we learnt about number patterns, which included linear sequences with a common difference and quadratic sequences with a common second difference.

1.1 Arithmetic Sequences

An arithmetic sequence is a sequence where consecutive terms are calculated by adding a constant value (positive or negative) to the previous term. We call this constant value the common difference (d).

Example: 3 ; 0 ; −3 ; −6 ; −9 ; …

  • First term (T1) = 3
  • Second term (T2) = 3 + (−3) = 0
  • Third term (T3) = 0 + (−3) = −3

1.2 The General Term Formula

If we know the first term and the common difference, we can find any term in the sequence without listing all the previous numbers. We use the General Term Formula:

Tn = a + (n - 1)d
  • a = The first term (T1)
  • d = The common difference
  • n = The position of the term (e.g., 1, 2, 3...)
  • Tn = The value of the term at position n

Exercise 1 – Finding the Next Terms

Find the common difference d and write down the next 3 terms.

1. 2 ; 6 ; 10 ; 14 ; 18 ; 22 ; …

Step 1: 6 − 2 = 4

Step 2: 10 − 6 = 4

∴ d = 4 ; next terms: 26, 30, 34

2. −1 ; −4 ; −7 ; −10 ; −13 ; −16 ; …

Step 1: −4 − (−1) = −3

Step 2: −7 − (−4) = −3

∴ d = −3 ; next terms: −19, −22, −25

3. −5 ; −3 ; −1 ; 1 ; 3 ; …

Step 1: −3 − (−5) = 2

Step 2: −1 − (−3) = 2

∴ d = 2 ; next terms: 5, 7, 9

Exercise 2 – Using the Formula

Use the formula Tn = a + (n-1)d to solve the following.

1. Determine the general term (Tn) for the sequence: 6 ; 13 ; 20 ; 27 ; ...

Step 1: Identify a and d.

a = 6

d = 13 − 6 = 7

Step 2: Substitute into formula.

Tn = 6 + (n − 1)(7)

Tn = 6 + 7n − 7

∴ Tn = 7n − 1

2. Determine the 50th term of the sequence: 2 ; 7 ; 12 ; 17 ; ...

Step 1: Identify a and d.

a = 2 ; d = 5

Step 2: Substitute n = 50 into formula.

T50 = 2 + (50 − 1)(5)

T50 = 2 + (49)(5)

T50 = 2 + 245

∴ T50 = 247

3. Which term in the sequence 5 ; 9 ; 13 ; ... is equal to 81?

Step 1: Identify variables.

a = 5 ; d = 4 ; Tn = 81

Step 2: Set up the equation.

81 = 5 + (n − 1)(4)

81 = 5 + 4n − 4

81 = 4n + 1

80 = 4n

∴ n = 20 (It is the 20th term)
