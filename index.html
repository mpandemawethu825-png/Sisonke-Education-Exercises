Exercise 1 – Arithmetic Sequences

Find the common difference d and write down the next 3 terms of each sequence.

1. 2 ; 6 ; 10 ; 14 ; 18 ; 22 ; …

Step 1: 6 − 2 = 4

Step 2: 10 − 6 = 4

Step 3: 14 − 10 = 4 → d = 4

Step 4: 22 + 4 = 26

Step 5: 26 + 4 = 30

Step 6: 30 + 4 = 34

∴ d = 4 ; next terms: 26, 30, 34

2. −1 ; −4 ; −7 ; −10 ; −13 ; −16 ; …

Step 1: −4 − (−1) = −3

Step 2: −7 − (−4) = −3 → d = −3

Step 3: −16 + (−3) = −19

Step 4: −19 + (−3) = −22

Step 5: −22 + (−3) = −25

∴ d = −3 ; next terms: −19, −22, −25

3. −5 ; −3 ; −1 ; 1 ; 3 ; …

Step 1: −3 − (−5) = 2

Step 2: −1 − (−3) = 2 → d = 2

Step 3: 3 + 2 = 5 → 7 → 9

∴ d = 2 ; next terms: 5, 7, 9

4. −1 ; 10 ; 21 ; 32 ; 43 ; 54 ; …

Step 1: 10 − (−1) = 11

Step 2: 21 − 10 = 11 → d = 11

Step 3: 54 + 11 = 65 → 76 → 87

∴ d = 11 ; next terms: 65, 76, 87

5. a ; 3b ; a + b ; a + 3b ; a + 5b ; …

Step 1: (a + b) − 3b = a − 2b (first difference not constant)

Step 2: (a + 3b) − (a + b) = 2b

Step 3: (a + 5b) − (a + 3b) = 2b → d = 2b from term 3 onwards

Step 4: a + 5b + 2b = a + 7b

Step 5: a + 7b + 2b = a + 9b

Step 6: a + 9b + 2b = a + 11b

∴ d = 2b ; next terms: a + 7b, a + 9b, a + 11b

6. −2 ; −½ ; 1 ; ½ ; 0 ; ½ ; 1 ; …

Differences: 1.5 → 1.5 → −0.5 → −0.5 → 0.5 → 0.5

The difference is not constant

∴ This is NOT an arithmetic sequence
