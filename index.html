Series and Sequences • Full Playlist

Key Concepts

  • Arithmetic Sequence: aₙ = a₁ + (n−1)d
  • Geometric Sequence: aₙ = a₁ · rⁿ⁻¹
  • Sum Arithmetic: Sₙ = n/2 [2a₁ + (n−1)d]
  • Sum Geometric: Sₙ = a₁ (rⁿ − 1)/(r − 1)
  • Infinite Series: S∞ = a₁/(1 − r) only if |r| < 1
Financial Mathematics • Complete Course

Key Concepts

  • Future Value Annuity: F = x[(1+i)ⁿ − 1]/i
  • Present Value Annuity: P = x[1 − (1+i)⁻ⁿ]/i
  • Compound Interest: A = P(1 + i)ⁿ
  • Effective rate: (1 + i_eff) = (1 + i/m)^m
Polynomials, Factor & Remainder Theorem

Key Concepts

  • Remainder Theorem: f(c) = remainder when divided by (x−c)
  • Factor Theorem: (x−c) is a factor ⇔ f(c) = 0
  • Cubic always has at least one real root
  • Possible rational roots = ± factors of constant / leading coefficient
